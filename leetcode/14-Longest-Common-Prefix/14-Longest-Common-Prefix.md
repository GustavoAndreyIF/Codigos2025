**14. Prefixo Comum Mais Longo**  
Fácil  

Escreva uma função para encontrar a maior string de prefixo comum entre um array de strings.

Se não houver nenhum prefixo comum, retorne uma string vazia "".

---

**Exemplo 1:**

Entrada: strs = ["flower","flow","flight"]  
Saída: "fl"

**Exemplo 2:**

Entrada: strs = ["dog","racecar","car"]  
Saída: ""  
Explicação: Não há nenhum prefixo comum entre as strings de entrada.

---

**Restrições:**

- 1 <= strs.length <= 200
- 0 <= strs[i].length <= 200
- strs[i] consiste apenas de letras minúsculas do inglês, se não for vazia.
